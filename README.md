# ∞ Quanta Microphone

A state-of-the-art blue/purple **infinity-themed landing page** for the Quantum Microphone framework — exploring phonon trace theory, frequency state models, and the Alpha–Gamma–Delta bridge between physical and quantum realms.

## 🌐 Live Site

Open `index.html` in any modern browser, or deploy via GitHub Pages.

## ✨ Features

- **Responsive hamburger navigation** with links to the www-infinity4 network
- **Animated infinity rings** hero section with glow effects
- **5 interactive Chart.js visualizations** — spectrum, radar, timeline, doughnut, scatter
- **Live phonon equalizer** — 48-bar animated frequency visualizer
- **Voice Key demo** — type any name to generate its phonon frequency and Access Port GPS
- **Planet section** — Uranus & Neptune as outer-resonance gas reservoirs
- **Blue/purple gradient design system** with smooth scroll-reveal animations
- Scientific disclaimer clearly separating speculative framework from established science

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| HTML | Semantic HTML5 |
| CSS  | Custom Properties, CSS Grid, Flexbox, Keyframe animations |
| JS   | Vanilla ES6+ (no framework) |
| Charts | Chart.js 4.4 (CDN) |
| Fonts | Inter + JetBrains Mono (Google Fonts) |
